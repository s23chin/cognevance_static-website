
# Cognevance Project 1: Cloud-Based Static Website Deployment

## Overview
A responsive demo website built using HTML, CSS and JavaScript to demonstrate static website hosting and cloud deployment.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- AWS S3 (deployment target)

## Project Structure
```text
cognevance_static-website/
├── index.html
├── css/style.css
├── js/script.js
├── screenshots/
├── docs/
└── README.md
```

## Run Locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deployment
The planned deployment target is AWS S3 static website hosting.
Deployment status and the public URL will be added after successful deployment.

## Security Notes
- Never commit AWS access keys or secrets.
- Do not collect real personal information through the demo form.
- S3 website endpoints do not provide HTTPS directly. Consider CloudFront for HTTPS.

## Monitoring
